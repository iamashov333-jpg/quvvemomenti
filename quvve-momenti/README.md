# Qüvvə Momenti & Sadə Mexanizmlər (8-ci Sinif Fizika Veb Saytı)

Bu layihə 8-ci sinif fizika dərslik proqramına və DİM qəbul proqramına tam uyğun olaraq hazırlanmış tədris portalıdır.

## 📦 Saytın Xüsusiyyətləri
1. **Nəzəri Hissə:** Qüvvə momenti, qüvvə qolu, saat əqrəbi istiqaməti qaydası, lingin tarazlıq şərti və sadə mexanizmlər.
2. **Biomexanika və Praktiki Həyat:** Qapı dəstəyi, bolt açarı, biseps və dirsək oynağı, ağır yük qaldırarkən onurğaya düşən moment.
3. **Qüvvə Momenti Kalkulyatoru:** F, d və bucağı daxil edərək real vaxtda hesablama.
4. **İnteraktiv Ling Simulyatoru:** Ağırlıqları və qolları dəyişərək lingin əyilməsini və tarazlıq halını canlı görmək imkanı.
5. **25 Suallıq 8-ci Sinif Quiz:**
   - 25 ədəd 8-ci sinif çətinliyində sual.
   - Sual nömrələri üzrə sərbəst naviqasiya.
   - Test bitdikdən sonra məktəb qiymətləndirməsi (2, 3, 4, 5) və faiz göstəricisi.
   - Hər bir sualın ətraflı elmi izahı.

## 🚀 Netlify-da Saytı Necə Yayımlamaq Olar? (Çox Sadə)

### Üsul 1: Drag & Drop (Ən tez üsul - 1 dəqiqəyə)
1. Brauzerdə [netlify.com](https://www.netlify.com/) saytına daxil olun və hesabınıza daxil olun (və ya pulsuz qeydiyyatdan keçin).
2. Əsas idarəetmə panelində (Dashboard) **"Sites"** bölməsinə keçin.
3. Səhifənin aşağısında **"Want to deploy a new site without connecting to Git? Drag and drop your site output folder here"** qutusunu görəcəksiniz.
4. Sadəcə kompyuterinizdəki **`quvve-momenti`** qovluğunu siçanla sürükləyib həmin qutunun içinə atın (Drop).
5. 5-10 saniyə ərzində saytınız internetdə canlı olacaq və sizə `https://...netlify.app` ünvanı veriləcək!

### Üsul 2: GitHub vasitəsilə
1. `quvve-momenti` qovluğunu GitHub repozitoriyanıza push edin.
2. Netlify-da **"Add new site" -> "Import an existing project" -> "GitHub"** seçin.
3. Repozitoriyanı seçin və **"Deploy"** düyməsinə basın (Build command və publish directory boş buraxıla bilər).
